名称：番茄钟 · 专注台
性质：自研实现（WorldHub 原创）
本地目录：tools/pomodoro/

组成：
  index.html        页面骨架、样式（单文件结构，零依赖）
  js/pomodoro.js    全部逻辑：计时、模式流转、任务、设置、周统计、SVG 猫、音频合成

机制：
  · 番茄循环：专注 → 短休息 → 专注 → 短休息 …… 达到目标轮数后进入长休息
  · 三段时长与目标轮数可设置（专注 1–180 分钟 / 短休 1–60 / 长休 1–120 / 轮数 1–12），
    设置有输入范围校验
  · 任务清单：可增删、勾选完成、点名称置顶为「本轮任务」；
    一段专注结束时被置顶的任务会自动标记完成
  · 本轮任务显示在计时器下方
  · 周统计：最近 7 天完成轮数的柱状图 + 本周累计轮数，存 localStorage
  · 专注时猫周围有呼吸光晕；猫用 SVG 自绘，随状态换表情
    （闲置 / 专注 / 短休 / 长休 / 暂停 / 完成）
  · 背景棕噪音与结束提示双音全部由 Web Audio 实时合成，不含任何音频素材文件
  · 支持全屏

设计说明：
  「番茄工作法」是一种通用的时间管理方法（定时专注 + 间歇休息），
  与任何具体作品无关；具体代码、界面、图形、音效均为本项目独立编写。
