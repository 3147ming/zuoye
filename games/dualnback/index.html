双重 N-Back 怎么玩

同时盯住"位置"和"字母"两条信息流，训练工作记忆。

  1. 网格里有个亮块在移动，中心会显示一个字母。
  2. 当亮块位置和 N 步之前一样时，按 A（位置匹配）。
  3. 当字母和 N 步之前一样时，按 L（声音匹配）。
  4. 两条流各自独立判断，可同时按。先稳再快。

从 1-back 起步；连续几轮稳定到 80%–85% 再升一级。每次练 15–20 分钟即可。
