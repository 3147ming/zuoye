### 7.2 关键设计决策（为什么不新增平台）

平台 id `breadboard` / `exp-box` 被 `model.loadCircuit()` 回退、存档 v4、暂存区
`stash[platformId]`、以及探针里大量 `exp-box:*` 节点 id 硬依赖。**新增第三个平台 id
会直接破坏存档兼容与既有探针**，因此采用「纯皮肤层」路线：

- `model.platform` 恒为 `exp-box`，几何 / 节点 / `pickAt` / 连线 / 存档一律不变。
- 只在 `view` 上加纯渲染层状态 `skin: 'hep' | 'classic'`；偏好写独立键
  `lab-sim:skin`，**不进电路存档 v4**。
- `layerKey(view)` 把 `skin` 纳入离屏平台层缓存键，切换时强制重建。
- HEP 写实皮肤只替换「平台层」绘制；元件、导线、悬停、探针标记等动态层不动，
  因此不干扰 `getImageData` 像素断言与拾取逻辑。
- 模块行为层是 DOM 覆盖层（`.hep-panel-layer { pointer-events: none }`，仅按钮
  `auto`），与 `probe-markers.js` 共用同一个 `onAfterRender(view)` 回调，按网格坐标
  `project()` 重投影，缩放 / 平移不漂移。
- 仪器前面板是纯装饰 DOM（`aria-hidden="true"`、`pointer-events: none`），
  `.inst-scope-canvas` / `.inst-measure` 等既有查询契约原样保留。

### 8.5 两处失败与修复

重写探针后首轮 84/86，两处都不是产品缺陷，但都做了实质修正：

1. **`关闭机箱丝印后模块铭牌区像素明显变化 → delta=0.0`**
   单点取样 `(6.4, 0.88)` 恰好落在中文字形缝隙里，且该处被后续绘制覆盖。
   实测画布整体校验和差 16952、铭牌带 115 点中 11 点变化、重新打开丝印后 115/115
   完全复原，证明功能正常。修法是把脆弱的单点断言换成**铭牌带多点聚合断言**
   （`silkBand()` 在网格 x∈[1.5,11.5] / y∈[0.7,1.7] 采样，要求 ≥5 点变化且总差 >200）。

2. **`点空白处后悬停信息卡隐藏` 失败**
   `clickAt()` 探针注入式点击没有配套 `pointermove`，只清了 `openId` 没清 `hoverId`，
   `refresh()` 仍判定 hover 卡可见。修法是**产品代码也一起改**：`onClick()` 与
   `clickAt()` 的空白分支同时清空 `hoverId / hoverHit / hoverPinned`，让触摸与注入式
   点击也能可靠收起信息卡（真实鼠标原本靠 pointermove 兜底，行为现在统一）。
