WorldHub 1.25.0 更新包
========================

本次新增：单机「弹弹岛」（六关抛物线对轰），原有联机玩法全部保持不变。

【怎么装】
1. 把这个包里的文件，按相同路径覆盖到你的 WorldHub 目录。
2. 重启本地服务（或推到 master 让 Cloudflare Pages 自动构建）。
3. 浏览器 Ctrl+F5 硬刷，核对 /version.json 显示 1.25.0。

【玩法入口】
大厅 → 游戏总门 → ✨ 大厅新玩 → 弹弹岛
也可直接打开 games/dandandao/index.html（离线可玩）。

【新增内容】
- 六关：新兵海湾 / 双礁伏击 / 高台狙击 / 三岛混战 / 强风岬 / 落日要塞
- 炮弹受重力与风力影响；地形可破坏，炸断的土整块塌进海里
- 敌人脚下被炸空落海也算击杀
- 三种弹药：标准弹（无限）/ 三连散 / 重弹，每回合补给
- AI 使用与玩家相同的弹道推演，按关卡调整精度
- ↑↓ 角度、←→ 力度、空格开火、1/2/3 换弹、G 切瞄准线
- 手机/触屏：往目标方向拖拽，松手发射
- 三星评价与解锁进度本地存档

【验证】
cd WorldHub
npm run test:dandandao     # 39 项端到端断言，全部通过
npm run test:party         # 联机自测 129 项

【注意】
- assets/app.41528cfd03.js 是新的首屏打包文件，index.html 已指向它；旧的 app.*.js 可以留着，不影响。
- games/dandandao/ 是新增目录，整个拷进去即可。
- 单文件版服务端 开服.mjs 已重新生成；前端按 WEB_ROOT 读磁盘，新游戏目录要在同一工程下。
