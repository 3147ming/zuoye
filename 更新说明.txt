WorldHub 1.24.4 → 1.24.8 更新包
================================

用法：把这个包里的所有文件，按同名路径覆盖到你的项目根目录
（README 里写的 D:\Projects\WorldHub），然后 git 提交推送即可。
不要删任何原有文件，这个包只是「覆盖」。

推送命令（在项目根目录执行）
----------------------------
git add -A
git commit -m "1.24.8: 修复碰碰全员出局、补七玩法操作说明"
git push origin master

推完等 1~2 分钟，打开 https://zuoye-e0c.pages.dev/version.json
看到 {"version":"1.24.8", ...} 就算上线成功。
如果还看到 HTML，说明构建还没跑完，或者构建失败了（去 Cloudflare 看这次提交的 check）。
