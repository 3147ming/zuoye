## 1. 安装与启动

- Windows：解压后双击 `run.bat`（自动起服务并打开浏览器）。
- 任意系统：在本目录执行 `node server.mjs`，浏览器打开 <http://127.0.0.1:5360/>。
- 需要 Node 18+；**不需要** `npm install`。必须用 `http://` 打开（ESM 在 `file://` 下会被浏览器拦截）。
- 端口被占用时：`set PORT=5361 && node server.mjs`（Windows）。

## 2. 界面导览

| 区域 | 用途 |
|---|---|

## 3. 常用操作

- **放元件**：点元件库 → 画布点放；勾"连续放置"可连放，Esc 退出。
- **连线**：点第一个端子再点第二个（点A点B），或按住端子拖到目标（拖拽释放）。
- **删线/删元件**：右键（画布内）直接删除；选中后按 Delete 也可以。
- **旋转**：选中元件按 `R`，四向 0→90→180→270。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`（或 `Shift+Ctrl+Z`）。
- **缩放**：滚轮；`+`/`-`；工具栏显示倍率；放大镜（`M`）可局部放大。
- **仿真**：电路一改自动重算（300ms 防抖）；数字电路可"时钟步进/触发脉冲"。
- **暂态**：波形面板点"运行"，设时长/步长；示波器/逻辑分析仪读最近一次结果。
- **仪器挂点**：万用表选测点/元件；示波器选 CH1/CH2；逻辑分析仪勾数字通道。
- **数据**：自动记录探针（10ms 一条），可暂停/清空、导出 CSV/JSON、存项目、截图。
- **示例实验**：实验列表里的 8 个示例，打开即载入模板；右侧指导书给步骤与预期值，"生成实验报告"导出单文件 HTML。
- **实验配置**：指导书下方可"应用方案 / 注入故障 / 评分"（预置 4 个方案）。

## 4. 示例实验怎么玩

1. E1 分压：万用表电压档测中点，应 2.500V；电阻档量 R1 应 1.000kΩ。
2. E2 LED：电流档测回路电流约 9.1mA；改 1k 限流电阻观察变化。
3. E3 RC：示波器 CH1 挂电容上端，运行 0.3s，t=0.1s 处应 3.16V。
4. E4 二极管：二极管档红笔 A、黑笔 K，读数约 0.7V；反接显示 OL。
5. E5 NPN：Rb 47k 时饱和（Vce≈0.12V）；换 470k 回到放大区。
6. E6 运放：跟随器输出 = 输入；断开反馈输出饱和到 3V。
7. E7 与非门：拨两个逻辑开关，对照真值表（只有 11 输出低）。
8. E8 分频：时钟 1kHz，逻辑分析仪读 Q 应 500Hz。

## 5. FAQ

1. **页面打开是空白/模块加载失败？** 用 `node server.mjs` 起服务，别直接双击 index.html。
2. **端口 5360 被占用？** `set PORT=5361 && node server.mjs`，或关掉占用进程。
3. **连不上线？** 终点必须是端子或孔位；两个端子不在同一平台/元件上会提示"终点不在当前电路上"。
4. **仿真不收敛？** 检查是否有电压源直连、电容直并电压源、跨域组合环路（状态行会给可读原因）。
5. **暂态没波形？** 先点波形面板"运行"；时长/步长要合理（步长大于时长只会采到两点）。
6. **示波器没有通道？** 先跑一次暂态；CH 列表只显示最近一次结果里的模拟通道。
7. **万用表电阻档读数不对？** 电阻档按"断电"处理（移除独立源）；带源测量请先断电。
8. **存档打不开？** 只接受本软件导出的 `.circuit.json`；坏文件会提示"文件损坏"且不改当前电路。
9. **数据太多卡顿？** 记录是每通道 10000 条环形缓冲，写满丢最旧；可"清空"或关闭记录。
10. **报告里没有截图？** 画布未渲染时截图为空；先切到实验台再看一次电路。
11. **元件参数改了没反应？** 参数面板改动会触发 300ms 防抖重算；看状态行是否"计算中…"。
12. **怎么交作业？** 指导书"生成实验报告"→ 单文件 HTML，浏览器打开后 Ctrl+P 打成 PDF。

## 6. 数据与隐私

全部数据在浏览器本地（localStorage + 下载文件），不上传任何服务器。

## 7. 画布探针标记（拖一下就挂测点）

仪器面板的测点除了下拉选择，还可以直接在画布上拖标记：

1. 画布左上角有 4 枚彩色标记：**DMM**（琥珀）、**DMM B**（红）、**CH1**（绿）、**CH2**（蓝）。
   没挂测点时停在托盘里，半透明显示「未挂」。
2. 按住标记拖到任意元件端子、面包板孔位或导线上松手，标记吸附到那里，
   并把该处所在的网络挂成对应槽位的测点（标签会显示 netId）。
3. 换测点就再拖一次；点标记右侧的 `×` 取消；仪器面板顶部的「画布探针」复选框可整体显隐。
4. 下拉框和标记是同一份数据：改任何一个，另一个立刻跟着变。测点与标记位置都会随
   项目存档（`.circuit.json`）保存，重新打开实验自动恢复。

提示：拖到空白处、或还没接线的孤立端子不会挂点（会提示「这里没有可测的网点」），
先把电路连好再挂探针。标记跟着画布缩放 / 平移，不会和电路错位。

## 8. 实物外观（HEP-DCTS-01）

按真实设备照片复刻的外观，打开「数字电路实验箱」时**默认就是实物外观**：
白色机箱 + 蓝色主板 + 2×3 共 6 块深蓝模块，仪器面板换成
SIGLENT SDS 1102CNL 示波器与 UTG9005A 函数信号发生器的前面板。

### 切换

画布工具栏的 **「实物外观」** 按钮：按下 = 写实皮肤，弹起 = 原来的通用实验箱。
偏好会记住，下次打开仍在。切到「面包板」平台时该按钮及下面两个显示按钮自动禁用、
模块面板隐藏，切回实验箱自动恢复。**只换外观，电路、连线、元件位置和存档都不会变。**

### 默认不铺满：悬停看信息、点击才操作

打开实物外观时，6 块模块**默认一张卡片都不显示**，蓝色主板、DIP 插座和机箱丝印
完整露出来。信息分三层，按需出现：

| 层 | 什么时候出现 | 长什么样 |
|---|---|---|
| ① 机箱丝印（静态） | 一直画在 canvas 上 | 模块名、档位、`+5V`/`GND`/`CON`、列号等白色丝印；可在「显示」里关掉 |
| ② 悬停信息卡（动态） | 鼠标移到某块模块或某个元件上 | 两行小卡：名称 + 状态摘要；纯展示、不吃鼠标事件，移开即隐 |
| ③ 可操作面板 | **点击**模块板 | 展开单张卡片，含位按钮 / 频率档位 / 逻辑笔读数等；可用图钉钉住 |

具体操作：

- **悬停**：移到 6 块模块板任一块（每块右上角有蓝色 LED 热点提示），或移到画布上的
  真实元件上，立刻浮出信息卡；模块板同时描一圈绿色亮边。
- **点击展开**：点模块板展开该模块的操作卡片；**一次只开一张**，点另一张自动收起上一张；
  再点同一张、点空白处或按 `Esc` 收起。
- **点到元件**：只把元件信息卡「钉住 / 取消钉住」，不会抢选中、连线或右键；点空白处取消。
- **图钉**：卡片右上角的「钉」按钮钉住后常驻，切外观前一直显示；再点一次取消。
- **总开关**：工具栏 **「模块面板」** 一键展开 / 收起全部 6 张，适合要一次性操作时。
- **显示选项**：工具栏 **「显示」** → 「机箱丝印」开关、「教学模式（全部常驻）」。
  这三项偏好记在 `localStorage` 的 `lab-sim:hep-view`，**不写进电路存档**，旧实验照常打开。
- **小屏（≤720px）**：展开的卡片自动改成底部抽屉，不再绝对定位盖住画布。

### 6 块模块能做什么

| 模块 | 说明 |
|---|---|
| LED 逻辑开关模块 A / B | 8 位拨动开关 + 状态指示。先在元件库放入「逻辑电平开关」，就能点模块上的位号逐位拨高 / 低电平，电路立即重仿；两个模块共 16 个位按钮 |
| IC 插座 / 逻辑笔模块 A | 显示电路里已插入的 14P / 16P 芯片，提示锁紧座与逻辑笔状态 |
| 七段数码管显示模块 | 取前 4 路逻辑开关作 BCD 输入，实时译码显示 `0`–`F`，下方列出 a–g 亮段 |
| 单脉冲 / 连续脉冲模块 | 「单次脉冲」「时钟步进」按钮 + 1Hz / 10Hz / 100Hz / 1kHz 频率档位（需先放入脉冲源 / 时钟源） |
| 电源 / CON / 逻辑笔模块 | `+5V` / `GND` / `CON` 状态；把 DMM 探针挂到网上后，按电压显示逻辑 `1` / `0` / `—` |

展开的卡片跟着缩放 / 平移移动，不会和电路错位；卡片上只有按钮可点，不会挡住你连线、
拖元件或右键删除。机箱上另有一组**实物状态灯**：8 路逻辑电平红灯、BCD 七段数码管
DS1、频率档位高亮框、逻辑笔电平灯，全部直接画进 canvas，随电路实时变化，不占任何屏幕空间。

### 仪器面板

切到「示波器」tab 会看到 SIGLENT SDS 1102CNL 前面板（CH1 / CH2 / EXT TRIG、
VERTICAL / HORIZONTAL / TRIGGER、RUN/STOP 等），切到「函数发生器」tab 会看到
UTG9005A 前面板（频率·幅度·键控·菜单·扫描、绿色数字键盘、TTL 输出）。
**这些是外观装饰，所有读数、按钮、波形和测点下拉的用法都和以前完全一样。**
切回通用实验箱外观时装饰层会消失。

### 常见问题

- **按钮是灰的 / 模块面板不见了？** 检查当前是不是「面包板」平台，实物外观只在
  「数字电路实验箱」下可用。
- **默认怎么一张卡片都没有？** 这是有意的：默认 0 张卡片，蓝色主板与 DIP 插座完整露出。
  鼠标移到模块上会浮出信息卡，点一下才展开操作面板；也可以点工具栏「模块面板」
  一键全展开，或在「显示」里开「教学模式」让它一直常驻。
- **想让某块模块一直显示？** 展开后点卡片右上角的「钉」，钉住后就不随点空白 / Esc 收起。
- **丝印太花想关掉？** 「显示」→ 取消勾选「机箱丝印」。品牌铭牌「数字电路实验平台 / HEP」
  是设备身份，会保留。
- **放了开关但位按钮还是禁用？** 先点开对应模块卡片；模块按电路里实际存在的
  「逻辑电平开关」生成，从元件库放入后会自动出现（也可以点模块里的「放入 4 路开关」快捷按钮）。
- **切外观后元件位置变了吗？** 没有。外观只是画法与覆盖层，`platform` 仍是
  `exp-box`，存档格式不变，旧实验可以直接打开。
