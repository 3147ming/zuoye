# 电路实验模拟器 · 开发文档（v1.0.0）

## 1. 架构

零依赖纯 ESM，无构建步骤。`node server.mjs` 起 5360 端口。

```
index.html
js/
  app.js          应用入口：视图切换、实验列表、右栏面板接线
  board.js        实验台编排：仿真调度、状态行、探针入口 __labBoard
  model.js        电路数据模型：元件/导线/网表/撤销栈/存档（v4）
  parts.js        元件外观 + 端子 + 参数面板描述
  symparts.js     原理图符号
  render.js       画布渲染 + pickAt（端子>元件>导线>孔位）
  interact.js     指针/键盘交互：放置、连线、旋转、右键删除、光标
  platforms.js    面包板 / 数字实验箱的孔位与器件
  solver.js       线性方程（高斯消元）+ 牛顿迭代
  devmodels.js    模拟元件模型（R/C/L/二极管/稳压管/BJT/运放/继电器/电位器…）
  simdc.js        直流工作点（MNA + 非线性 NR + 结果/报告）
  digmodels.js    数字逻辑模型（74LS00/02/04/08/32/86/74）
  simdig.js       数字稳态求值（三值逻辑 + 拓扑排序 + 环路检测）
  simtrans.js     暂态（梯形积分 + 事件驱动 TPD + 分帧运行器）
  simmix.js       混合信号边界（比较器/DAC/ADC/缓冲 + 跨域环路）
  waveview.js     波形查看器
  instruments-core.js / instruments.js   四件仪器（读数内核 / 面板）
  datastore.js / data-panel.js           数据系统（记录/CSV/JSON/存档迁移）
  examples-data.js / examples-measure.js / report.js  示例实验与报告
  experiment-config.js                   方案/故障注入/评分
  version.js      版本号单点
tools/
  check.mjs       静态语法检查（node --check 的替代，ESM 友好）
  test-model.mjs  模型/求解器自测（467 条）
  test-all.mjs    全量回归（静态 + 自测 + tools/probe/run*.mjs）
  bench.mjs       性能基准 B1–B5
  gen-examples.mjs 示例模板复算与生成
  probe/          各包验收探针（run5/6/7/8/…/13、probe14、runA/runB）
```

**数据流**：交互 → `model`（唯一数据源）→ `board.handleChange` → 防抖 300ms → `simulateNow`（DC+数字+混合）→ 面板/画布。暂态由波形面板/仪器显式触发。

**单一数据源原则**：读数、报告、模板、评分全部调用同一套 `solve*` 与 `examples-measure`，不允许 UI 层自己算一遍。

## 2. 仿真内核

| 内核 | 文件 | 说明 |
|---|---|---|
| 直流 | simdc.js | MNA 装配、接地可达性剪枝、短路检查、非线性牛顿（PN 结限幅 + 精修两段） |
| 数字 | simdig.js | 三值逻辑、拓扑排序、组合环检测、74 系列门/触发器 |
| 暂态 | simtrans.js | 电容梯形伴随（首步 BE）、电感梯形支路、时钟/脉冲绝对时刻、门 TPD 事件队列、分帧运行 |
| 混合 | simmix.js | VCC/2 阈值、DAC D/255·Vref、ADC round(V/Vref·255)、跨域瞬时依赖图环路检测 |

**数值口径**：电压 V、电流 A、电阻 Ω、电容 F、电感 H；存档只存用户参数与 type，模型常数不落盘。

## 3. 元件模型表

| type | 模型 | 关键参数 |
|---|---|---|
| resistor | 欧姆 | resistance (Ω) |
| capacitor | 直流开路 / 暂态梯形 | capacitance (F)、dielectric |
| inductor | 直流短路 / 暂态梯形支路 | inductance (H) |
| diode | 指数 Is/n | model: 1N4148 / 1N4007 |
| zener | 正向指数 + 反向雪崩 | vz |
| led | 指数（型号决定 n） | color、model: ideal/red/green/yellow/blue |
| transistor | Ebers-Moll | model: 2N2222 / 2N3906、beta |
| opamp | 有限增益 + 摆幅钳位 | model: LM741 / OP07 |
| relay | 线圈 100Ω + SPDT（30mA 吸合/20mA 释放） | — |
| pot | 两端电阻按滑臂分压 | resistance、wiper(%) |
| dip4 | 4 个独立开关 | s1..s4: on/off |
| buzzer | 有源 100Ω / 无源 1kΩ | mode |
| comparator/buffer74/dac8/adc8 | 混合边界（simmix） | threshold/hysteresis/vref |
| fgen | 正弦/方波/三角/直流 | wave/frequency/amplitude/offset/duty |

## 4. 存档 schema（v4）

```json
{
  "version": 4,
  "platform": "breadboard",
  "components": [{ "id": "r1", "type": "resistor", "x": 2, "y": 2, "rotation": 0, "params": {} }],
  "wires": [{ "id": "wire-1", "a": { "componentId": "r1", "terminal": "1" }, "b": { "componentId": "v1", "terminal": "+" } }],
  "stash": {},
  "instruments": { "tab": "dmm", "dmm": {}, "scope": {}, "la": {} },
  "records": []
}
```

迁移：`datastore.migrateArchive`（v1 数组导线 → 对象、补 stash/instruments/records；未来版本拒绝迁移）。
往返一致：`archivesEquivalent` 排除 time/savedAt/updatedAt 后逐字节比较。

## 5. 验收方法

```bash
node tools/check.mjs          # 28/28
node tools/test-model.mjs     # 467/467
node tools/test-all.mjs       # 全量：889+ 项，写 tools/probe/log/test-all-result.json
node tools/bench.mjs          # B1-B5，写 tools/bench-result.json
node tools/gen-examples.mjs   # 示例模板复算（13/13）
node tools/build.mjs          # 打包 dist/ 并自检独立启动
```

探针约定：每个脚本末尾输出 `=== 探针结果：N/M 通过 ===`；test-all 用该行判定，**不看退出码**（长跑进程可能被环境回收）。

**更新线上副本（改完源码后三步）：**

```bash

DEST=/d/Projects/_github_pages/ming-games/circuit-lab
cp -r dist/js/. "$DEST/js/" && cp -r dist/css/. "$DEST/css/" \
  && cp -r dist/examples/. "$DEST/examples/" && cp dist/index.html "$DEST/"  # 2. 覆盖子目录
# Windows / Git Bash 没有 rsync；有 rsync 的环境可等价用：
#   rsync -a --delete dist/js dist/css dist/examples dist/index.html "$DEST/"
cd /d/Projects/_github_pages/ming-games && git add -A \
  && git commit -m "update circuit-lab" && git push   # 3. 推送即自动构建
```

- 子目录部署要求**全部相对路径**：`index.html` 用 `js/app.js`、`css/main.css`，JS 里不得出现
  以 `/` 开头的 `fetch`/`src`。当前代码满足（`grep -rn 'src="/' index.html` 为 0），新增资源时别破坏它。
- 大厅卡片数据在 `index.html` 的 `GAMES` 数组，本项目那条 `url: 'circuit-lab/'`、`order: 8`、
  `orientation: 'landscape'`；封面 `covers/lab.png`（1280×800）。
- `D:/Projects/HUB` 是 surge 入口镜像（`ming-games.surge.sh`），页面是主站副本 + `const BASE`
  前缀，卡片跳 pages.dev；主站加卡片后要把它 `cp` 过去并保留 BASE 那行再 `npx surge ./deploy`。

## 7. 画布探针标记与数字结构缓存（2026-11-04）

### 7.1 画布可拖拽探针标记

- 模块：`js/probe-markers.js`（新增）；槽位契约在 `js/instruments.js` 导出的 `PROBE_SLOTS`。
- 四槽位 DMM / DMM B / CH1 / CH2，各自 `scope + key` 指向 instruments 状态字段。
  `setProbe(slot, netId)` 与下拉 `setDmm / setScope` 写**同一份状态**，`onProbeChange`
  回调让标记层同步，所以两个入口永远不会打架。
- 落点解析走 `board.pick(x, y)`：terminal → `netOf['c:…']`，node → `netOf['n:…']`，
  wire → 端点 `getNetOf`，component → 第一个端子。孤立端点 / 空白落点不挂点并给 toast。
- 标记位置存**网格坐标** `{ gx, gy }`（不是屏幕像素），写在
  `instruments.snapshot().markers` 里随 v4 存档走；`restore()` 自动回填，
  没有位置时会落到该网第一个元件端子上。未挂测点时停靠画布左上托盘。
- 视图跟随：`board.js` 的 `requestRender()` 每帧调 `board.onAfterRender(view)`；
  标记层 `onViewFrame()` 只在 `originX/originY/tileW/tileH/width/height` 变化时重投影，
  避免每帧写 DOM。注册 / 注销在 `app.js` 的 `wireInstruments()` / `destroyInstruments()`。
- 探针：`tools/probe/probe-markers.mjs`，由 `test-all.mjs` 按 `probe*.mjs` 自动发现。

### 7.2 B3 电路指纹结构缓存

- `js/simdig.js`：`circuitSignature()` 生成指纹（元件 id/type/params + 端子→网映射 +
  TTL 悬空策略 + 平台），命中则复用 `buildDigPlan()` 产出的
  `units / sources / drivers / order / unitByKey`，省掉收集与拓扑排序。
- **边界**：只缓存结构。每步仍清空 `levelIn / levelOut / edge / mode / invalid`、
  重算源电平、触发器记忆与混信边界输出；`resetDigState()` 同步清缓存。
  比较器 / ADC 的输出电平依赖本步模拟电压，特意留在 `solveDig()` 里重算，
  不进 `buildDigPlan()`（否则闭包会捕获旧的电压表，输出会被冻住）。
- `__labBoard.simdig.cache() / resetCache()` 供探针读命中数；`tools/test-model.mjs`
  有 7 条缓存回归（命中 / 参数失效 / 连线失效 / 时钟运行态不缓存）。
- 缓存改造时踩过的两个坑（已修）：组合 / 跨域环路早退分支要补回 `hasDigital`，
  否则面板误报"电路里没有数字元件"；混信求值上下文不能搬进结构构建函数。
