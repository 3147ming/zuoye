# 自建内容接入契约

大厅允许任何人往里放自己的页面。放进来之后，它会出现在「工具总门」或「游戏总门」的选单里，
玩家选中就会被传送到它自己的区块——和内置的九款走同一套逻辑。

## 三步

1. **建目录**：`contrib/<你的 id>/index.html`，页面依赖全放这个目录里（css / js / 图片都可以）。
2. **注册**：在 `contrib/manifest.js` 里调一次 `WorldHub.register({...})`。
3. **自检**：`node tools/check-contrib.mjs`，全绿再交。

## 注册字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| `id` | 是 | 小写字母、数字、连字符，2–32 位，全站唯一；同时是存档里的场景名，**定了别改** |
| `name` | 是 | 显示名，≤ 24 字 |
| `cat` | 是 | `games` 或 `tools`，决定归哪座总门 |
| `src` | 是 | 只能是仓库内的相对路径，不许 `http(s):` / `data:` / `../` |
| `desc` | 否 | 选单里那行小字，≤ 28 字，默认「自建内容」 |
| `color` | 否 | 门与徽点的颜色，`#rrggbb`，默认 `#9b8afb` |
| `author` | 否 | 署名，≤ 20 字 |

```js
WorldHub.register({
  id: 'my-game',
  name: '我的游戏',
  cat: 'games',
  src: 'contrib/my-game/index.html',
  desc: '一句话说明',
  color: '#7fb0ff',
  author: '某某'
});
```

## 页面要求（这些是硬约束，校验脚本会查）

- **零外部请求**：不许引 CDN（jQuery、字体、图标都不行）。要依赖就把文件拷进自己的目录。
  原因：整个大厅要能 `file://` 双击直开，断网也得跑。
- **传统 `<script>`**：不能用 `<script type="module">`。`file://` 下 ES Module 会被 CORS 挡掉。
- **自适应**：会被塞进 1280×720 的 iframe 里，别写死超过这个尺寸的布局。
- **自己处理键盘焦点**：玩家点进你的页面后，`Esc` 归你；想回大厅点右上角「← 返回大厅」。
- **不要动 `localStorage` 里 `worldhub.*` 开头的键**：那是大厅的存档、偏好与背景。

## 审核口径

`tools/check-contrib.mjs` 查的是「能不能安全地跑起来」，不是「好不好玩」：

1. 字段是否合法（长度、格式、id 唯一）；
2. `src` 指向的文件是否存在、是否在 `contrib/` 下；
3. 入口 HTML 里有没有外链（`http://`、`https://`、`//cdn`）；
4. 有没有用 `type="module"`；
5. 目录体积是否离谱（单个条目 > 40MB 会提示）。

闸门过了，人工再看一眼玩法与署名，就能并进主线。

## 停用

设置面板 →「自建内容」里可以逐条开关。关掉的条目不会出现在选单里，
但文件与注册代码仍在——适合临时排查「是不是我这一条把大厅搞崩了」。
