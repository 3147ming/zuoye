# 基于Web的2D横版世界大厅游戏合集设计与实现

一个纯前端的单页小游戏合集入口：用一张 2800×720 的横版卷轴地图当「大厅」，
玩家操控角色在其中行走、跳跃，走到传送门前即可进入对应的小游戏。

本项目为课程大作业，**完全独立**，与任何既有项目无关；**只在本地运行，不部署线上**。

---

## 一、运行方式

直接双击 `index.html` 即可（`file://` 协议下可用，全部脚本都是传统 `<script>`，没有 ES Module 的跨域限制）。

如需本地静态服务器（可选）：

```bash
cd D:\Projects\WorldHub
python -m http.server 5350
# 浏览器打开 http://127.0.0.1:5350/
```

### 操作

| 按键 | 动作 |
| --- | --- |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格`（也支持 `W` / `↑`） | 跳跃，长按跳更高 |
| `E` | 与守灯人对话 |
| `H` | 打开 / 关闭操作说明面板 |
| `Esc` | 关闭帮助或对话；在小游戏里回大厅 |

## 三、核心设计

### 3.1 场景管理器（`js/sceneManager.js`）

统一场景接口，四个方法缺一不可，切场景时**先 `destroy()` 旧场景，再 `init()` 新场景**：

```js
init(ctx, params)   // 进入场景，准备资源
update(dt)          // 推进逻辑，dt 单位为秒
render(ctx)         // 绘制，坐标系固定 1280×720
destroy()           // 离开场景，释放监听 / 定时器 / 图片
```

- **逻辑分辨率固定 1280×720**，实机像素由 `devicePixelRatio` 决定（上限 2 倍），
  CSS 只负责等比缩放，所以任何窗口尺寸下画面都不变形、不裁切。
- 主循环统一用 `requestAnimationFrame`，`dt` 钳制在 50ms 以内 ——
  切到后台再切回来时不会因为累积时间过大而一帧穿地。
- 场景接口不完整时直接抛错，避免半成品场景混进注册表。

### 3.2 横版大厅（`js/world.js`）

- **地图 2800×720**，地表线 `GROUND_Y = 566`，角色 x 被限制在 `[44, 2756]`，跑不出边界。
- **五层视差**：远山 0.10 → 丘陵 0.22 → 远林 0.42 → 近林 0.70 → 地面 1.00，
  再往前叠**两层**前景草叶（1.12× 与 1.34×），形成「远—中—近—贴脸」四段纵深。
- **静态素材预渲染**：天空渐变、太阳、云带合成为一张 1280×566 的离屏画布；
  纸纹生成 128×128 噪点图后转成 `CanvasPattern`；光斑做成着色好的 sprite 反复 `drawImage`。
  逐帧只建 2~3 个渐变，其余全是画路径 / 贴图，稳定 60fps。
- **确定性随机**：所有山脊、树、草丛用 `mulberry32(20261102)` 生成，
  每次刷新地图长得一模一样，方便调试和截图比对。
- **画面语言**：剪纸黄昏 —— 分层纯色剪影 + 背光暖边 + 叠加纸纹，
  近景更暗、远景更亮，用明度差而不是描边来做层次。

### 3.3 角色与手感（`js/player.js`）

普通的「加速度 + 重力」很容易做出塑料感，这里补了四个细节：

| 机制 | 参数 | 作用 |
| --- | --- | --- |
| 加速度 / 摩擦分离 | 加速 2800、摩擦 2400 px/s² | 起步跟手，松手滑一小段但不打滑 |
| 土狼时间（Coyote Time） | 0.10s | 刚离开地面边缘还能起跳，不会「明明按了却没跳」 |
| 跳跃缓冲 | 0.14s | 落地前按空格也算数，落地瞬间自动起跳 |
| 可变跳跃高度 | 松手时 `vy = max(vy, -300)` | 轻点小跳、长按大跳 |

下落时重力额外乘 1.28，让滞空时间更短、落地更「实」；落地按速度触发压缩形变，起跳则纵向拉长。

**摄像机**（`Camera`）用帧率无关的指数平滑 `1 - e^(-6.5·dt)` 跟随，
目标点带上「面朝方向 +64px」的前视偏移 —— 往哪边走，哪边看得更远。

### 3.4 传送门

五道门分别对应贪吃蛇、森林冰火人、二人格斗、与AI打牌、记忆翻牌，位置写死在 `world.js` 的 `portals` 数组里：

| 传送门 | 地图 x | 主题色 |
| --- | --- | --- |
| 贪吃蛇 | 706 | `#5fd39a` |
| 森林冰火人 | 1128 | `#79c8ff` |
| 二人格斗 | 1612 | `#e8545f` |
| 与AI打牌 | 2094 | `#e8b45a` |
| 记忆翻牌 | 2500 | `#a98ae0` |

每道门由「石框 + 能量腔 + 上升流光 + 图腾 + 名字牌」组成，呼吸式明暗；
门内图腾各不相同（蛇身曲线 / 火与冰晶 / 交叉双刃 / 三张牌 / 两张扇形展开的牌）。

角色横向进入门中心 ±62px 时会**直接切入对应场景**（`SceneManager.has(id)` 命中即 `change(id)`）。
五款游戏均已接入，进入时 `body[data-scene]` 变为场景名，CSS 据此隐去大厅标题与按键提示。

进门前会把角色位置写进存档；回大厅时站在原地，名字牌下方多一枚「已通关 ✓」小吊牌
（只有森林冰火人 / 二人格斗 / 与AI打牌 三门会点亮，贪吃蛇与记忆翻牌是本地纪录型玩法，不参与通关标记）。
存档点本身就在门的触发范围里，所以回到大厅的那一帧会先把这扇门认作「当前门」，
走出 ±62px 再走回来才会重新进入 —— 否则会变成「一出来就被弹回游戏」的死循环。

### 3.5 NPC 与对话

大厅的「守灯人」站在 x=470，是一套完整的两态交互：

- 靠近 80px 且站在地面 → 角色头顶浮出气泡「按 E 与我说话」，底部提示条同步显示；
- 按 `E` 打开对话面板（DOM 覆盖层），每按一次 `E` 推进一句，第 8 句再按关闭；
- 说话中走开 120px 自动关闭；`Esc` 也关；面板不阻塞移动；
- 对话内容写死在 `world.js` 的 `lines` 数组里（8 句），`npc.js` 只负责状态机与渲染，
  换文本不用动逻辑。

### 3.6 五款小游戏

全部是独立场景文件，共用 `SceneManager` 的接口，互不引用。

| 游戏 | 场景名 | 玩法要点 | 回到大厅 |
| --- | --- | --- | --- |
| 贪吃蛇 | `snake` | 31×17 格、每格 40px，速度随分数递进（0.12s → 最快 0.06s），WASD / 方向键、禁止 180° 掉头 | `Esc` / 结算面板按钮 |
| 森林冰火人 | `fireice` | 单人用 `Tab` 切火人 / 冰人，岩浆只伤冰人、水池只伤火人、毒液双杀，**6 关**：闸门 → 升降平台 → 锁门压力板 → 传送阵 | `Esc` / 通关面板按钮 |
| 二人格斗 | `fight` | 1280×720 定屏、三局两胜，双人对战与挑战 AI 双模式，拳 8 / 踢 14、无敌帧 0.5s、空中下落攻击、**满能量放必杀** | `Esc` / 结算面板按钮 |
| 与 AI 打牌 | `cards` | 简化斗地主，54 张、随机地主、全部标准牌型，AI 只做「最小可压 / 要不起」 | `Esc` / 结算面板按钮 |
| 记忆翻牌 | `memory` | 1280×720 定屏、4×8 共 32 张牌（8 种符号各 4 张）配 16 对，翻转 0.12s、错配锁定 0.8s，本地最佳用时 | `Esc` / 结算面板按钮 |

五款都遵守同一套约定：**所有按键与点击监听在 `init` 挂、`destroy` 摘**，
`Esc` 一律回大厅，结算面板用画布绘制并按逻辑坐标做命中检测。

#### 3.6.1 冰火人第 4–6 关的三种新机关

| 机关 | 所在关 | 口径（都能按公式复算） |
| --- | --- | --- |
| 升降平台 | 第四关 | 顶面 `y = yBase + amp·sin(phase + t·omega)`，`amp = 120`、`omega = π`（即 0.5Hz、周期 2s），两块相位相反，只能先后踩 |
| S3 压力板 + G3 锁门 | 第五关 | G3 高 4 格（跳不过去）；踩板解锁，**松脚后从松开那一刻起算，保持 3.0s** 再上锁 |
| T1 ↔ T2 传送阵 | 第六关 | 站满 **0.25s** 触发，0.35s 粒子动画，落地后 **0.3s 无敌**、该阵 **0.5s 冷却**，必须走出阵外才能再传 |

平台落地用的是「脚底贴上顶面」的软吸附：站在上面时 `y` 每帧对齐平台顶面，
实测 240 帧内偏差 < 0.01px，不抖也不穿。

#### 3.6.2 格斗能量必杀

- 能量 0–100：拳中 +8、踢中 +12、被击中 +6；**自己血量 ≤30 时上述全部 ×2**（+16 / +24 / +12），封顶 100。
- 释放：P1 按 `L`，P2 按 `3`（或小键盘 `3`）。**只有满能量才成立**，没满只飘一句「能量不足」。
- 伤害 30、击退 `vx = 550`、释放瞬间 0.6s 无敌、命中全屏冲击波 + 「必杀！」飘字，命中判定沿用拳的 `hitBox`。
- 双方同时放必杀会互相被对方的无敌帧抵消（先判定谁先起手），不会出现「两边同时掉血」。
- AI 在 `aiDecide` 里多一条分支：**自身满能量且距离进入可命中范围时优先放必杀**，放完归零回到常规决策，两个角色机制完全对称。

### 3.7 音效（`js/audio.js`）

- **零素材**：不加载任何音频文件，15 个音效全部用 Web Audio 的振荡器 + 增益包络现场合成，
  参数写在 `RECIPES` 表里（波形 / 起止频率 / 时长 / 增益 / 偏移），想调音色只改这张表。
- **浏览器自动播放策略**：`AudioContext` 在**首次用户手势**（keydown / pointerdown / touchstart）时才创建，
  之前所有 `play()` 直接静默返回；不支持的浏览器（或创建失败）会置 `failed` 并永久静默。
- 主增益 0.5，单音 0.03–0.10，连续触发也不会糊成一片。
- 接入点：大厅 `jump / land / portal / talk / ui`，贪吃蛇 `eat / dead / ui`，冰火人 `ui / dead / win`，
  格斗 `hit / kick / ult / win`，打牌 `play / pass / win`，记忆翻牌 `ui / match / miss / win`。
- 想静音：`Audio.setEnabled(false)`（或 `Audio.enabled = false`），不会影响任何玩法逻辑。

### 3.8 开场与帮助

- **开场标题卡**：进入大厅时 `intro = 2.5`，在 `update` 里按 `dt` 递减，**不拦任何逻辑**；
  `render` 末尾叠一层黑幕 + 「世界大厅 World Hub」+「五道门，五个世界」+ 底部「按 E / 空格 / 回车 跳过」。
  按 `E` / 空格 / 回车 / 点击画面都只做一件事：把 `intro` 置 0。
- **帮助面板**（`H` 开关，纯 canvas 覆盖层）：一张表列出大厅与五款小游戏的全部键位（8 行，格斗 P1 / P2 分行），
  文案集中在 `world.js` 的 `HELP_ROWS` 里，**和真实键位逐字一致**（改键位请顺手改这里）。
  面板打开时 `Esc` **优先关面板**，不会顺手把角色传回大厅。

### 3.9 HUD

画面里的中文全部走 DOM 覆盖层（`position:absolute` + 容器查询单位 `cqw`），
跟着舞台等比缩放 —— 比画在 canvas 上更清晰，也天然支持 `aria-live` 的提示播报。
左上角是标题 **世界大厅 World Hub**，右上角是操作提示，底部是传送门提示条。

## 五、演示流程（答辩建议顺序，约 3 分钟）

按下面的顺序走一遍，正好覆盖**全部五个场景 + 存档 + 音效 + 帮助**，不留死角。

1. **开场（0:00–0:15）** —— 双击 `index.html`。标题卡 2.5 秒淡入：「世界大厅 World Hub」/「五道门，五个世界」。
   说一句「这一段只递减一个 `intro` 计时，不拦任何逻辑」，顺手按 `E` 演示跳过。
2. **大厅与帮助（0:15–0:45）** —— `A`/`D` 走、空格跳（长按更高、松手截断），走到守灯人按 `E` 连推两句对话。
   按 `H` 打开帮助面板，指出「这张表就是真实键位，集中写在 `HELP_ROWS`」；按 `Esc` 演示**优先关面板**而不是回大厅。
3. **贪吃蛇（0:45–1:05）** —— 进第一道门吃两个果子（`eat` 音效），故意撞墙看结算（`dead`），`Esc` 回大厅。
   强调门牌**不亮**通关吊牌：它是无尽模式，只在本地留最高分。
4. **森林冰火人（1:05–2:00）** —— `Tab` 切火 / 冰人，先在第 3 关展示岩浆只伤冰人、水池只伤火人。
   重进直接选第 4 关踩**升降平台**（相位相反，要等它升过台沿）；第 5 关踩 `S3` 解锁 `G3`，
   **松脚后金环倒计时 3 秒**；第 6 关踩 `T1` 蓄力 0.25 秒传到 `T2`。
   打通第 6 关看到「六关全通」，回大厅后冰火人门牌亮起「已通关 ✓」。
5. **格斗必杀（2:00–2:25）** —— 选「挑战 AI」，先挨两下再打回去，指出血条下方的能量条
   （拳 +8 / 踢 +12 / 挨打 +6，血量 ≤30 时翻倍）。满 100 后按 `L`：白闪冲击波 +「必杀！」+ 击退 550。
6. **打牌 / 记忆翻牌 / 存档（2:25–3:00）** —— 打牌用 `空格` 出牌、`F` 提示，赢一局点亮第三枚吊牌；
   记忆翻牌翻两对看 `match` / `miss` 音效与最佳用时；`Esc` 回大厅后**刷新页面**，
   角色站在原地、三枚吊牌还在 —— 收尾落在「存档模块」这条主线上。

### 存档

状态存于独立模块 `js/save.js`（localStorage key：`worldhub.save.v1`），不挂在场景对象上：

- 进传送门时记录角色位置，回大厅 `init` 时恢复（`x` 限定在 `[44, 2756]`，越界视为无效）；
- 森林冰火人（**六关全通**）/ 二人格斗（仅挑战 AI 且玩家胜）/ 与AI打牌（玩家阵营胜）通关后，
  对应传送门名字牌下显示「已通关 ✓」，刷新页面仍在；
- 贪吃蛇（无尽模式）与记忆翻牌（计时挑战）不参与通关标记，只在本地留最高分 / 最佳用时；
- 所有读写都包在 `try/catch` 里：隐私模式、配额满、存档被写坏（坏 JSON / 越界坐标 / 类型不对）
  都只会回落到默认值，不会影响游戏运行。想重置进度，清掉这条 localStorage 即可。

```js
Save.get()                       // 读整份存档（永远返回合法结构）
Save.setPlayer(x, facing)        // 记录位置，进传送门时调用
Save.complete('fireice')         // 标记通关，只接受 fireice / fight / cards
Save.isCleared('fight')          // 查标记
Save.reset()                     // 清空（调试用）
```
